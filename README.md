# Voice Solitaire

Accessible card game for blind players with voice, haptic, and audio cues.

## Setup
1. Copy the voice-solitaire folder to your Android device (Internal Storage).
2. Open My Files > voice-solitaire > Tap index.html > Choose Chrome.
3. In Chrome, tap the 3-dot menu > Add to Home Screen.
4. Enable TalkBack (Settings > Accessibility > TalkBack > On).
5. Tap the Voice Solitaire icon to play.
6. Use voice commands: "start game", "draw card", "describe board", "undo", "read about", "save game", "quit game", "next level".

## Features
- 5 levels (easy to hard).
- 5 undos per game.
- Save game on exit (say "save game" or "quit game").
- Tracks score per game and total, with high score announcements.
- Fully offline, no internet needed.

## Notes
- Requires Chrome for voice commands.
- Data saves to localStorage.
- To update, replace the voice-solitaire folder with a new version.
- Personal use only. Do not resell.
